# 鲜绿草地 · 花草交错

花园地面改为疏密、高低各不相同的草丛，穿插矮小野花，与原来的高花形成层次。草叶具有弯曲轮廓、叶脊、嫩绿渐变和柔和高光，叶片上的露珠会随风一起摆动。小路、角色脚边、花车与招牌周围留有空间。

新增的小花也会在星夜亮起暖色微光。以下是浏览器实际运行截图。
