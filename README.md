# STAYREAL PARK · 微缩公园

React + Three.js 制作的互动微缩场景，灵感来自逐梦花园、海上望月与荷你相见三张海报。非官方演示作品。

[查看毛绒花园实际截图](docs/previews/README.md) · [天气漫游实际截图](docs/previews/weather-tour.md)

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci --cache /tmp/stayreal-npm-cache
npm run dev -- --port 3000
```

浏览器访问开发服务的 3000 端口。拖动旋转、滚轮缩放；移动设备支持单指旋转、双指缩放。

```sh
npm run build
npm run preview -- --port 3000
```

构建产物为 `dist/`，可部署到静态网站服务。需要支持 WebGL 的现代浏览器。

## 交互

- 三个场景自由切换，包含小兔、花草、蜜蜂、游船、水波与热气球动画。
- 兔子结合实体公仔与毛绒概念图调整造型：宽领口藏入下巴，窄白衣边接红色条纹，花园背带裤的腰臀与短裤腿连续成型；保留饱满脸颊、立体兔耳、曲面五官与花环。头部摆动以肩颈连接处为轴。
- 第一个场景采用毛绒与毛毡风格：真实短纤维轮廓、程序化布料纹理、牛仔缝线、毛毡花朵及蜜蜂装胡萝卜，搭配鲜绿草丛与露珠。
- 毛绒纤维通过实例化绘制；动画最高 30 帧/秒，花园阴影按需刷新，暂停时按视角和天气变化绘制。无需额外外部素材。
- 左侧「天气漫游」保留晨曦、晴空、落日、雨幕、虹光、飘雪、星夜七种氛围。点击名称直接选择，拖动滑杆平滑过渡；方向键逐项切换，Home / End 到达两端。云朵采用融合的立体曲面，天气颜色与光照同步变化。
- 兔子的上衣与袖子融合成连续曲面，肩部通过骨骼权重柔和变形，挥手时保持衔接。
- 逐梦花园切到「星夜」时，花坛、拱门、花车、花环及手持花朵会渐亮，伴随暖色光晕与轻盈光点；切回其他天气平滑熄灭。暂停会冻结光点与呼吸动画。
- 草地由高低错落的弯曲草叶与小花交错组成，保留小路和角色脚边空间；叶片有嫩绿渐变和水润高光，露珠随草叶轻摆。新增小花同样参与星夜发光。
- 右侧工具支持缩放、视角复位、暂停与全屏。
- 氛围音需用户点击开启，使用 Web Audio 合成柔和音色。
- 所有模型使用程序化几何生成；字体不可用时自动使用系统字体。
