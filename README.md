# schedule · 个人学习笔记本

一个使用 Vue 3 制作的个人学习规划与日记应用。它把每日计划和当天心情放进一本手绘风格的数字笔记本里，适合记录不同时间段的学习安排，也适合写下每天的小片段。

## 功能

- 按日期切换笔记本页面
- 添加不同时间段的学习计划
- 勾选完成、删除和清除当天计划
- 记录每日札记与心情
- 计划和日记自动保存到浏览器本地
- 五颗不同颜色的球形角色作为一套整体 Logo
- 纸张、舞台幕布、贴纸和手绘线条风格

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

然后打开终端显示的本地地址。

## 构建

```sh
npm run build
npm run preview
```

项目可以部署到 GitHub Pages 等静态网站服务。

## 技术栈

- Vue 3
- Vite
- CSS 手绘视觉样式
- LocalStorage 本地数据保存
